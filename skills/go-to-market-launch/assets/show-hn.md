# Show HN Post — <product or finding>

_Prepared <date> · Target: <weekday morning US Eastern> · Built by: <you>_

> HN rewards honesty and punishes marketing voice. Post only if it is interesting *on its own merits*. The comment thread is the content; be there for it.

## Title

Pick the honest, plain one. No emoji, no "the best", no clickbait.

- If it's a tool: `Show HN: <plain one-line description of what it does>`
- If it's a write-up or finding: `<plain, specific title — the actual claim, not a tease>`

Examples of the *shape* (invent your own, do not reuse):
- `Show HN: I built a simple invoice tool for freelancers`
- `How I cut our onboarding drop-off in half with one email`
- `Show HN: A free comparison of <X> pricing across 12 vendors`

Avoid: superlatives, "just launched", growth-hack framing, anything that sounds like a landing page.

## Body (the first comment, from you)

Keep it short, first-person, and factual. Cover:

- **What it is**, in one plain sentence.
- **Why you built it** — the real reason, ideally a problem you had.
- **How it works** — one or two sentences of the interesting mechanism, not a feature list.
- **What's imperfect / what you'd like help with** — HN respects this; it invites useful critique.
- **That you built it** — say so plainly. It's a Show HN; pretending otherwise gets you flagged.
- **Link** — the UTM-tagged URL from `tracking.md`.

Draft:

> <One sentence: what it is.>
> I built it because <the real reason / the problem you hit>.
> <One or two sentences on how it works or what's genuinely new about it.>
> It's still rough in <honest weak spot> — I'd especially value feedback on <specific question>.
> Link: <URL>

## Day-of

- [ ] Post in the morning, US Eastern; commit the day
- [ ] Be in the comments from the first minutes
- [ ] Answer **technical questions first**, then the commercial ones
- [ ] Reply to skeptics with substance; do not get defensive
- [ ] Never ask for upvotes or share vote-begging links — it gets you flagged
- [ ] Fix anything embarrassing that comes up and say that you fixed it

## Etiquette that matters here

- Post it only if it stands alone as something a stranger would find useful or interesting.
- Plain title, honest body, disclose authorship.
- No vote rings, no "please upvote", no cross-posting the same text to bait traffic.
- If it dies, that's information, not a catastrophe — try a different angle another day, not the same post again.

## After

- [ ] Reply to the late questions
- [ ] Log the real traffic/signup numbers; check the UTM source
- [ ] Write a specific build-in-public post about what HN actually did
- [ ] Thank the people who gave genuine technical feedback

## Boundary

The founder posts and replies under their own account. The agent drafts only — it never submits or comments.
