## Product one-liner

## ICP (ideal customer profile)

<The one narrow segment you serve first — role, context, and the specific painful job.
Not "anyone who wants to be organised". One segment at a time.>

## Stage

<idea | validating | building | launched | growing | steady-state — plus the single
number that proves it, e.g. "launched: 3 paying customers, $120 MRR".>

## North-star metric

<The one number that best represents value delivered to customers. Usually revenue /
MRR. Everything else is an input to it.>

## Stack

<The boring, holdable default: language / framework, hosting, database, payments,
analytics, and the coding agent. Zero custom auth or payments. Every tool you add is
a future debugging session.>

## Current constraint

<The one bottleneck that, if cleared, unblocks everything else *right now* — cash,
distribution, churn, a scope decision, or your own attention. This is the field the
router reads first; if it is vague, the routing will be too.>
